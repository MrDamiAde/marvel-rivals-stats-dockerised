# Marvel Rivals Stats

I built this project because I play **Marvel Rivals daily** and thought, why not build something useful and fun around it?

This is a full-stack web app that shows the health, speed, and abilities of various characters from the game. It was also a chance for me to practice Docker, Flask, PostgreSQL, and real-world app structuring.

---

## 🚀 What I Did

- Built the backend with **Flask** (Python)  
- Designed a clean dark-themed UI using **Bootstrap**  
- Created a responsive layout with **character cards and detail pages**  
- Hooked everything up to a **PostgreSQL database**  
- Containerised the entire app using **Docker & Docker Compose**  
- Used **Docker volumes and networks** to manage isolated services

---

## 🐳 How to Run Locally

Make sure Docker is running, then:

```bash
docker-compose up --build
```


Visit the app at: http://localhost:5000

## 📦 Tech Stack

- Python 3.11

- Flask

- PostgreSQL 13

- Docker

- Docker Compose

- HTML, Bootstrap 5
